# VS Code × OpenAI Codex 拡張機能 完全セットアップ & 活用ガイド

VS CodeにおけるOpenAI提供の**Codex拡張機能**の導入から、ワークスペースの作成、`/init` コマンドを使った `AGENTS.md` の自動生成、そして実践的な使い方までを網羅したガイドです。

---

## 概要: Codex拡張機能とは？

Codex拡張機能は、リアルタイムでコードを補完する従来のツール（GitHub Copilotなど）とは異なり、**指示を与えて複数ファイルにわたる修正・機能追加・エラー解消を自律的に任せる「AIエージェント」**として動作します。

---

## 1. ワークスペースの作成と拡張機能のインストール

### Step 1: ワークスペース（プロジェクトフォルダー）の作成
1. パソコン上の任意の場所に作業用フォルダー（例: `my-codex-project`）を作成します。
2. VS Codeを起動し、上部メニューの **「ファイル」>「フォルダーを開く...」** を選択します。
3. 作成したフォルダーを選択して開きます。（「このフォルダーの作成者を信頼しますか？」と表示された場合は「はい、作成者を信頼します」を選択）
4. （任意）複数フォルダーを管理する場合は、メニューの **「ファイル」>「名前を付けてワークスペースを保存...」** で `.code-workspace` ファイルを作成します。

### Step 2: Codex拡張機能のインストール
1. VS Codeの左アクティビティバーにある **拡張機能アイコン**（四角が4つ並んだマーク）をクリックします。
2. 検索窓に `Codex` と入力します。
3. 発行元が **OpenAI** の「Codex」（または `Codex – OpenAI's coding agent`）を選択し、**「インストール」** をクリックします。

### Step 3: サインイン（認証）
1. サイドバー（または右上）に追加された **Codexアイコン** をクリックしてパネルを開きます。
2. **「Sign in with ChatGPT」**（または「ChatGPTでログイン」）をクリックします。
3. 自動でブラウザが起動するため、対象の有料プラン（Plus / Pro / Team / Enterprise 等）が有効なChatGPTアカウントでログインを完了させます。

---

## 2. `/init` コマンドによる `AGENTS.md` の作成と初期化

Codexには、プロジェクト構造を自動認識して最適な設定ファイル `AGENTS.md` を生成する `/init` コマンドが用意されています。

### 手順
1. **`/init` コマンドの実行**
   VS Codeでプロジェクトフォルダーを開いた状態で、Codexチャットパネルの入力欄に以下を入力して送信（Enter）します。
   ```text
   /init
   ```
2. **プロジェクトのスキャンとファイル生成**
   Codexがプロジェクト内のディレクトリ構造や設定ファイル（`package.json` 等）をスキャンし、ルートディレクトリに `AGENTS.md` が自動生成されます。

3. **日本語運用ルールの追記（カスタマイズ）**
   生成された `AGENTS.md` を開き、末尾に以下のようなカスタムルールを追記して保存します。

```markdown
## Custom Rules
- **言語方針**: 会話、説明、確認メッセージ、ファイル内コメントはすべて「日本語」で行ってください。
- **実行権限**: ファイルの作成・削除・大幅な書き換えを行う場合は、事前に何を修正するか日本語で説明し、承認を求めてください。
```

## 3. 基本的な使い方と実践ワークフロー

### 安全かつ効果的な頼み方（3ステップ）

1. **まずは提案・確認から始める**
   * 💬 *「このプロジェクトの構文エラーや改善点を、実行はせずに候補だけ3つ日本語で挙げてください」*
2. **実行を依頼する**
   * 💬 *「提案の1番を実行してコードを修正してください」*
3. **差分（Diff）を確認して反映する**
   * Codexが修正案を作成すると画面上にコードの差分が表示されます。
   * 内容を確認し、問題が無ければ **「Accept（採用）」** をクリックして実際のファイルへ変更を確定させます。
